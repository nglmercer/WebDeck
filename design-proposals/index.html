Propuestas de rediseño — «Configura tu botón»

Tres direcciones interactivas e independientes para el modal de configuración de botón (ejemplo: Pulsar una tecla del teclado). Abre cada propuesta a pantalla completa para probarla: capturar teclas, buscar, mover el tamaño y cambiar el color funcionan.

V1 · Evolución

Refinada

El mismo flujo de una columna, bien ejecutado. Menor coste de implementación.

  • Secciones claras con pie fijo (Cancelar / Guardar)
  • Lista de teclas con estados hover / seleccionada
  • Captura con estado visible + tamaño y color sincronizados

Compacta

Tarjeta estrecha y moderna para pantallas táctiles pequeñas.
