# Translation catalogs

Translations live in `webdeck/translations/<locale>.json`. Each catalog is a flat UTF-8 object with string values. Locale IDs such as `en_US` and `es_ES` remain unchanged in saved configuration.

`en_US.json` is the single canonical English source. The frontend's `src/lib/messages.ts` is a generated, typed fallback containing only `ui_*` entries; do not edit it manually. This keeps the rest of the locale catalogs out of the JavaScript bundle.

## Editing copy

1. Edit the English JSON value under a stable `ui_*` key. Keep existing keys stable.
2. Add translations under the same key in the other catalogs. Missing entries fall back to English; a locale does not need to duplicate every English entry.
3. Preserve named placeholders such as `{label}` and `%count%`. JSON escaping supports quotes, line breaks, equals signs and Unicode without a custom file parser.
4. Run `npm run i18n:generate --prefix frontend` and `npm run check:i18n --prefix frontend`.

The frontend build regenerates the English fallback automatically, without rewriting unchanged output. Validation checks the flat string shape, duplicate keys, unknown UI keys, placeholder parity, static interface text and fallback freshness.

To add a locale, copy an existing JSON catalog to the new locale ID and update `native_name`, `english_name`, `lang_code`, `author_name` and `author_github_username`. Translate string values, not keys. Existing compatibility entries and attribution metadata are preserved.

## Runtime behavior

The Rust endpoint merges the English catalog with the configured locale and returns the existing flat translation response. Missing or invalid selected catalogs fall back to English. Locale names must be safe basenames, so configuration cannot read an arbitrary JSON file outside the translation directory.

Development reads JSON catalogs from disk. Production embeds the JSON files and the locale list alongside the frontend; packaged binaries can load them without a checkout. The frontend continues to use per-session translation context, escaped Svelte text, and the existing interpolation helper.
